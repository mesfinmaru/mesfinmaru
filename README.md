## 👨‍💻 About Me

I'm an **Information Systems student at Debre Berhan University** who builds scalable web applications, data pipelines, and enterprise tools that solve real-world challenges, with a focus on making technology work in local contexts.

- 🌐 **Full-Stack & Distributed Systems**: APIs and web apps with FastAPI, React, Node.js, PHP, and ASP.NET Core
- 📊 **Data Engineering & Analytics**: event-driven pipelines with Kafka, PostgreSQL, ClickHouse, MinIO, and CRISP-DM
- 🔐 **Cybersecurity & Systems**: Kali Linux, network security, penetration testing, and virtualized labs
- 🤝 **Community Participation**: Contributing in **DBU Tech Tonic Tribe Cyber Division**, organizing CTFs and technical workshops
